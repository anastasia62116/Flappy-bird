# Flappy Bird — учебный веб-прототип

Небольшая браузерная игра на чистых HTML, CSS и JavaScript. Сторонние библиотеки и внешние файлы не нужны.

## Как запустить

1. Распакуй папку проекта.
2. Открой `index.html` в современном браузере.
3. Нажми на игровое поле или клавишу `Пробел` / `↑`, чтобы начать.
4. Во время игры нажимай или касайся поля, чтобы птица взлетала.

Для локального запуска без ограничений браузера можно использовать расширение Live Server в VS Code или выполнить в каталоге проекта:

```bash
python -m http.server 8000
```

Затем открой http://localhost:8000.

## Управление

- Клик или касание — взмах крыльями.
- `Пробел`, `↑` или `Enter` — начать игру / взлететь.
- Кнопка «Звук» — включить или выключить звуковые эффекты.
- Рекорд сохраняется в `localStorage` этого браузера.

## Файлы

- `index.html` — структура страницы.
- `style.css` — адаптивная вёрстка.
- `game.js` — игровая логика, Canvas-графика, физика и звук.

Веб-версия готова к публикации как статический сайт. Для создания мобильного приложения на Android или iOS потребуется дополнительно настроить проект Capacitor и добавить необходимые платформенные файлы.
